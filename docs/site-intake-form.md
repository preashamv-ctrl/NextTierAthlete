# NextTierAthlete — Initial Site Submission Form

Purpose: the bare minimum needed to reserve an athlete's subdomain and kick off their site build. This is intentionally short — it's a "start the build" form, not the full content collection.

Once a site build starts, the fuller **Content Checklist** in `docs/template-case-study.md` (Section 3, "Content Checklist") covers everything needed to actually launch: stats, bio, photos, academics, schedule, coach references, etc. That's collected separately, after this form, during onboarding (see `docs/business-plan.md` Section 8, "Client Onboarding Workflow").

---

## Fields

| # | Field | Type | Required? | Notes |
|---|---|---|---|---|
| 1 | Athlete Full Name | Text | Required | |
| 2 | Parent/Guardian Name | Text | Required | Primary point of contact |
| 3 | Parent/Guardian Email | Email | Required | Primary contact + where the invoice/next-steps email goes |
| 4 | Parent/Guardian Phone | Phone | Optional | |
| 5 | Primary Sport | Select: Football / Basketball / Baseball / Softball / Soccer / Volleyball / Track / Other | Required | "Other" reveals a free-text field |
| 6 | Graduation Year | Select (current year through +6) | Required | Used for recruiting-class framing on the site |
| 7 | School / Club Team | Text | Required | |
| 8 | Package | Select: Rookie / Varsity / Elite / Content Capture / Not sure yet | Required | "Not sure yet" is fine — sales call will confirm |
| 9 | Preferred Site Name | Text | Optional | e.g. "firstlastname" for `firstlastname.nexttierathlete.com` — subject to availability, confirmed during onboarding |
| 10 | Anything else we should know? | Textarea | Optional | Open field — second sport, timeline, special requests |

That's it — 6 required fields, 4 optional. No stats, no photos, no bio text at this stage; those come later so this form doesn't become a barrier to a parent just getting started.
