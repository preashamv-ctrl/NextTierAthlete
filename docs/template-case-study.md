# Case Study & Template Spec: The NextTierAthlete Recruiting Site
### Based on maxwellpreasha.preasha-home.com

This document turns Maxwell's existing site into (1) a case study you can show prospective clients and (2) a reusable spec so every future client site hits the same bar.

---

## 1. What This Site Gets Right (Use in Sales Conversations)

| Feature | Why It Works | Sales Talking Point |
|---|---|---|
| Clean hero section with class year, school, position(s), one-line identity statement | Coaches scan fast — the essentials are visible in 3 seconds | "This is what a coach sees in the first glance — no scrolling required." |

| Consistent brand motif (repeated tagline/typography) | Feels like a real athlete brand, not a template dump | "Every site gets its own consistent identity, not a generic layout." |
| Prominent "Recruiting inquiry" CTA in the main nav | Makes the site's purpose obvious immediately | "The whole site is built around one goal: getting a coach to make contact." |

## 2. Gaps on the Current Build (Fix Before Sending to Any Coach)

These are the standard QA checkpoints for every site going forward — nothing ships to a client (or gets sent to a coach) with any of these unresolved:

- [ ] **Film section populated** — never ship with a placeholder message. At minimum: one embedded highlight reel.
- [ ] **Stats/measurables block** — height, weight, key testing numbers (40 time, vertical, etc.), and sport-specific stats (PPG/assists/rebounds for basketball; passing yards/TDs/completion % for football, etc.)
- [ ] **Academic info** — GPA, standardized test scores if available, intended major/academic interests (many coaches at D2/D3/NAIA weigh this heavily).
- [ ] **Working contact form** — never "coming soon." Test it end-to-end before go-live.
- [ ] **Schedule section** — upcoming games/showcases so coaches can plan in-person viewing.
- [ ] **Real photo gallery** — actual game/practice photos, not a single graphic.
- [ ] **Coach/reference contacts** — current coach's name and contact info (with permission), plus any private trainers or club coaches willing to serve as references.

## 3. Standard Template Spec (v1) — Use for Every New Client Site

### Site Structure
1. **Home/Hub** — hero (name, class, school, position, identity line), quick-glance stat strip, CTA to recruiting inquiry, links to sport-specific sub-pages if multi-sport.
2. **Sport Profile Page(s)** — one per sport: bio, stats/measurables, embedded film, photo gallery, schedule.
3. **Film Room** — organized highlight library (season-by-season or game-by-game), full-game film links where available.
4. **Academics** — GPA, test scores, intended major, any academic honors.
5. **Contact/Recruiting Inquiry** — functional form routed to parent/guardian email, plus listed coach references.

### Design Standards
- Mobile-first (most coaches will open the link on a phone).
- One consistent visual identity per athlete (color, typography, tagline) — distinct enough to feel like a personal brand, not a reused shell.
- Fast load time — compress images/video embeds, avoid heavy unoptimized graphics.

### Content Checklist (Client Intake → Site)
- [ ] Full bio + identity statement
- [ ] Class year, school, position(s)
- [ ] Stats/measurables (current, update each season)
- [ ] At least one embedded highlight video at launch (this is where in-house filming closes the gap if the family has no existing footage)
- [ ] 5–10 real photos minimum
- [ ] GPA/test scores/academic interests
- [ ] Schedule (season dates, showcases, combines)
- [ ] Coach/reference contact info
- [ ] Working, tested contact form
- [ ] Any third-party rankings/evaluations (link out)

## 5. Next Steps for Maxwell's Site Specifically

Since this is likely your own flagship/demo site, closing its gaps first makes it a fully credible sales asset:
1. Film at least one game or practice session (using your own capture capability) to fill the film section.
2. Add a stats block (even placeholder "season in progress" stats if early in a season).
3. Activate the contact form.
4. Add a schedule section with upcoming games.
5. Add a real photo gallery from a game or practice shoot.

Once these are done, this site can be shown to prospective clients as a live, fully functional example rather than a work-in-progress.
