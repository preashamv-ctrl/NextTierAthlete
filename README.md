# NextTierAthlete

Recruiting websites, social media management, and game/practice content capture for youth athletes (ages 12–18).

This project builds and manages two things for each athlete client: (1) a personal recruiting website (stats, highlight film, academics, coach contacts, schedule) that can be sent directly to college coaches, and (2) ongoing social media management (Instagram/TikTok/X) that grows the athlete's visibility and builds a personal brand for recruiting and NIL opportunities.

## Background

Originally scoped under the working name "Prospect Path" and later rebranded to NextTierAthlete. Flagship example/demo site: `maxwellpreasha.preasha-home.com`.
